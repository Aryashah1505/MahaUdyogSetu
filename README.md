# 📌 About the Project

**Maha Udyog Setu** is a modern web platform developed as a solution-oriented project for **Smart India Hackathon 2026**.

The platform aims to provide users with a centralized digital ecosystem where they can access relevant information, services, resources, opportunities, and business-related support through a simple and accessible interface.

The project focuses on:

- Simple and modern UI/UX
- Centralized access to services
- Intelligent assistance
- Secure user authentication
- Business and entrepreneur support
- Easy navigation
- Responsive design
- Scalable architecture

---

# 🎯 Objectives

The major objectives of Maha Udyog Setu are:

1. Provide a centralized platform for users.
2. Simplify access to important services and resources.
3. Improve the overall digital user experience.
4. Reduce complexity caused by scattered information.
5. Provide intelligent assistance wherever required.
6. Create a responsive platform that works across devices.
7. Build a scalable architecture suitable for future expansion.

⚙️ Prerequisites

Before running the project, make sure you have installed:

Node.js

Install Node.js from:

https://nodejs.org/

Check installation:

node --version
npm --version
Git

Check Git:

git --version
📥 Installation

Clone the repository:

git clone https://github.com/PatelDwij/MahaUdyogSetu.git

Move into the project directory:

cd MahaUdyogSetu

Install dependencies:

npm install
🔑 Environment Variables

Create a .env file in the root directory.

Example:

VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

GEMINI_API_KEY=your_gemini_api_key

TWILIO_ACCOUNT_SID=your_twilio_account_sid
TWILIO_AUTH_TOKEN=your_twilio_auth_token
TWILIO_PHONE_NUMBER=your_twilio_phone_number
Important

Never commit your real API keys or secrets to GitHub.

Make sure .env is included in .gitignore.

▶️ Run the Project Locally

After installing dependencies:

npm run dev

The development server will start.

Open the URL shown in the terminal, generally:

http://localhost:5173
🏗️ Production Build

To create a production build:

npm run build

A successful build generates the production files inside:

dist/
▶️ Run Production Server

After building:

npm start
🔍 TypeScript Check

To check the project for TypeScript errors:

npm run lint
👀 Preview Production Build

You can preview the Vite production build using:

npm run preview
